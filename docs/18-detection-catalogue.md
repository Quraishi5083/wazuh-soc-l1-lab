# 18. Detection Catalogue

| **Rule** | **Logic** | **Test case** | **Status** | **Likely false positives** | **Tuning idea** |
|---|---|---|---|---|---|
| 100101 (level 10) | Sysmon Event 1, parent `cmd.exe`, image `powershell.exe` | `cmd` then `powershell` (Phase 4 process tree) | Confirmed working by the author; live patterns are looser than intended (Section 10.8) | Admin scripts, installers and logon scripts that call PowerShell from a batch file | Exclude known script paths or signed parents; raise only with an encoded command or a network event |
| 100102 (level 10, T1053.005) | Event 1, image `schtasks.exe`, command line contains `/create` | `schtasks /Create ... /SC ONLOGON` (Phase 3) | Confirmed working: alert shown in Figures 5.7 and 11.2 | Software updaters and IT management tools creating tasks | Allow-list known task names and parents; raise when the task action runs PowerShell or an encoded command |
| 100103 (level 8) | Event 3 group `sysmon_event3`, image `powershell.exe`, protocol `tcp` | `curl.exe` and `nslookup` tests (Phase 6) | **Unresolved**: no alert on a real Event 3 | Almost any PowerShell web request, so it would be noisy | Fix the match first, then restrict to non-private destinations or unusual ports |
| 92027 (level 4, built-in) | PowerShell spawned PowerShell | `powershell -NoProfile -Command "Get-Date"` | Fired (Phase 3) | Very common | Informational only |
| 60122 / 60118 (built-in) | Failed logon / workstation logon success | Controlled wrong-password test (Phase 5) | Fired (Phase 5) | Mistyped passwords, stale service credentials | Use frequency rules (several failures from one source) rather than single events |
| 554 (level 5, built-in) | FIM: file added to a monitored path | Test file added to the Startup folder (Phase 10) | Fired (Figures 12.5 to 12.8) | Installers and updaters adding files | Raise severity for executables and scripts in Startup (Section 12.10, sketch) |
| FIM modified (level 7, built-in; ID to confirm) | Size, time or checksum changed on a monitored file | Appended one line to the test file | Fired (Figures 12.11, 12.12) | Software updates, configuration edits | Alert on sensitive paths first; find the responsible process with who-data or Sysmon |
| FIM deleted (level 7, built-in; ID to confirm) | Monitored file removed | `Remove-Item` on the test file | Fired (Figures 12.14, 12.15) | Cleanup and uninstalls | Review deletions of system binaries and logs first |
| Vulnerability Detection (built-in module, not a rule) | Installed package version falls in a CVE's vulnerable range (here below 26.01) | 7-Zip 25.01 installed (Phase 11) | Finding listed; cleared after the update to 26.04 and an inventory refresh (Figures 13.8, 13.9) | Fixes backported without a version change; stale inventory | Triage by CVSS, exposure and real use of the software; confirm closure in both the host and the SIEM |
